# 模型带骨骼导出 · 操作清单

> 目标：拿到一份**带骨骼**的模型文件，放进 Godot 工程。
> 全程大概 5 分钟，最麻烦的是第 3 步（如果平台没有绑定功能）。

---

## 步骤 0 · 准备

1. 打开浏览器，登录你生成这个模型的平台（文件名显示是 **Tripo**）
2. 找到「安理oc」这个模型
3. 记下它的模型详情页地址（万一要回来重试）

---

## 步骤 1 · 看有没有「绑定」

在模型详情页找下面任意一个入口：

- 标签叫 **Rig** / **绑定** / **骨骼** / **Skeleton**
- 或者下载弹窗里有 **Include Rig** / **包含骨骼** / **With Skeleton** 的勾选项

**有 → 走步骤 2**
**没有 → 跳到步骤 3**

---

## 步骤 2 · 导出带骨骼版本

1. 点 **Download / 导出**
2. 格式选 **FBX**
3. 勾上 **Include Rig / 包含骨骼**（如果有这个勾选项）
4. 下载
5. **如果下载下来是 .zip**：先解压，取出里面的 .fbx（上次那份就是 zip 改了后缀，Godot 直接读会报 "Unrecognized file format"）
6. 把文件改名为 `model_rigged.fbx`
7. 放到这个目录：

```
C:\Users\22818\StudioProjects\cards3d\assets\model_rigged.fbx
```

8. 告诉我「放好了」，我接着验证

---

## 步骤 3 · 平台没有绑定 → 用 Mixamo

1. 浏览器打开 **mixamo.com**
2. 注册 / 登录（免费 Adobe 账号，不要用公司账号）
3. 点 **Upload Character**，上传这个文件：

```
C:\Users\22818\StudioProjects\cards3d\assets\model.fbx
```

4. 自动绑骨向导会要求你拖关节点：**下巴、手腕、手肘、膝盖、脚踝**
   - 这是 Q 版模型，头大手短，**手肘和膝盖的关节点容易偏**，拖的时候对着关节位置放
5. 绑好后进入动作库，搜 **Idle**，挑一个待机动作
6. 右侧 **Download**：
   - Format 选 **FBX Binary (.fbx)**
   - **勾上 With Skin**
7. 下载的文件改名为 `model_rigged.fbx`
8. 放到同一个目录：

```
C:\Users\22818\StudioProjects\cards3d\assets\model_rigged.fbx
```

9. 告诉我「放好了」

---

## 步骤 4 · 两条都失败时的备选

回到 Tripo，下载一份**未压缩的 GLB**（下载弹窗里如果只有一种 GLB，就换 FBX）。

1. 改名为 `model_raw.glb`
2. 放到：

```
C:\Users\22818\StudioProjects\cards3d\assets\model_raw.glb
```

3. 告诉我，我来试着直接从里面读骨骼

> 背景：你最早给的那份 GLB 里其实**有骨骼**（1 套 skin、80 根骨骼节点），
> 只是被 meshopt 压缩了，Godot 解不开。换未压缩版本就有机会直接读到。

---

## 验收标准（我拿到文件后会做的）

1. 打开文件，数骨骼节点数量，打印骨骼名
2. 如果找到 `Skeleton3D`：
   - **有动画** → 找 `AnimationPlayer`，循环播 idle
   - **没动画** → 按骨骼名程序化驱动（等待抱臂、结算点头、被罚低头）
3. 如果读不出骨骼 → 回报错误信息，回到步骤 4 换格式

---

## 一句话总结

**去 Tripo 看一眼下载列表有没有「带骨骼」，有就导 FBX 发我；没有就去 Mixamo 绑一次。**

不需要重新生成模型，也不需要找人重做。
